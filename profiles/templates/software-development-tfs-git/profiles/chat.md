# Chat note observations

| Chat evidence | Proposed result |
| --- | --- |
| Attributed result report for a scoped item | reports_result attributed to that speaker |
| Explicit complete scoped work item mention | references when the source record has an evidenced identity |
| Name resemblance to tracker or Git label | Unresolved identity |

Keep the reporter and the reported subject separate. Preserve a report's stated
scope and unknowns. A forwarded report does not become an independent result.
Stop at the last complete statement when the producer marks the note truncated.
