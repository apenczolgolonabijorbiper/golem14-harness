# Guided Golem setup for Codex CLI and Desktop

Use the active Codex session as the inference host. Read integration/SETUP.instance.md
from this same harness and follow its guided setup procedure. Propose application
docs/GOLEM_CODEX.md as the reusable setup record, unless an existing selected
record or the user specifies another location.

Read the application-root AGENTS.md explicitly and check for AGENTS.override.md
and more local instructions. Start CLI sessions from the application root. In
Desktop, use the application as the primary project folder and verify the current
folder/revision, including whether this chat is in a worktree. Resolve the private
instance independently of a new worktree's relative location before any writes.
Use the instance selected in the setup record and ask if paths conflict.

Check that the current sandbox can reach the private instance and adapter.
Request only the missing access through the host's supported controls. Keep the
setup pending when access is unavailable. Follow docs/CODEX.md for launch and
verification examples. The existing Codex login supplies inference in this session.
